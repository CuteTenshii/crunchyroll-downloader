# Desktop GUI (Wails) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Wails hybrid desktop GUI (dark cinema / warm orange) that Inspects Crunchyroll catalogs, multi-selects options with sensible defaults, downloads via the existing Go engine, and saves preferences.

**Architecture:** Extract shared logic into `internal/engine` so CLI (`cmd/cli`) and GUI (`cmd/gui` + `frontend/`) call the same Inspect/Download APIs. GUI uses Wails v2 bindings and events for progress. Secrets stay file-path-only in preferences under `%AppData%/crunchyroll-downloader/`.

**Tech Stack:** Go 1.25+, Wails v2, vanilla HTML/CSS/JS frontend (no heavy framework required), existing gowidevine/go-mpd, FFmpeg at runtime.

**Spec:** `docs/superpowers/specs/2026-08-02-desktop-gui-design.md`

- [ ] **Step 1: App methods**

```go
func (a *App) StartDownload(job engine.DownloadJob) error {
	if a.cancel != nil {
		return fmt.Errorf("job already running")
	}
	ctx, cancel := context.WithCancel(a.ctx)
	a.cancel = cancel
	go func() {
		defer func() { a.cancel = nil }()
		cfg := engine.DefaultRuntimeConfig()
		// apply prefs advanced → cfg; set Widevine env from prefs paths if set
		err := engine.RunDownloadJob(ctx, job, cfg, func(ev engine.ProgressEvent) {
			runtime.EventsEmit(a.ctx, "progress", ev)
		})
		if err != nil {
			runtime.EventsEmit(a.ctx, "progress", engine.ProgressEvent{
				Phase: engine.PhaseDone, Level: "error", Message: err.Error(), Fraction: -1,
			})
			return
		}
		runtime.EventsEmit(a.ctx, "progress", engine.ProgressEvent{
			Phase: engine.PhaseDone, Level: "ok", Message: "All done", Fraction: 1,
		})
	}()
	return nil
}

func (a *App) CancelDownload() {
	if a.cancel != nil {
		a.cancel()
	}
}
```
