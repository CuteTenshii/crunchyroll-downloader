## Project (what this tool is)

Downloads DRM-protected Crunchyroll anime the operator is entitled to, using **their** `etp_rt` file and **operator-owned** Widevine credential. Pipeline: auth → CMS/playback → MPD → license → segments → decrypt → ffmpeg MKV (H.264/AAC/ASS). Widevine **only at download time**. Subtitle-only index is CDM-free. Secrets: file paths only, mode ~0600, never argv/logs/git.

GUI: Wails v2, tags `desktop,production`, WebView2. Theme: dark cinema, **orange accent** (not purple). Locale default **pt-BR**.
