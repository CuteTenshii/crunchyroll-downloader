<objective>
Replace the RAM-heavy segment concatenation path with temp-file streaming, make segment concurrency configurable, and harden the media helpers so malformed adaptation sets and temp-file failures surface cleanly.
</objective>

<tasks>

`type`: auto
`files`: main.go, internal/download/episode.go, internal/media/segment.go
`action`: Thread a configurable worker count from the CLI into `DownloadParts`, replace the hard-coded worker pool, and keep segment progress reporting by segment count.
`verify`: Run a download with a small worker count and confirm the worker budget affects segment concurrency without breaking the progress counter.
`acceptance_criteria`: The segment worker pool is configurable and still reports progress the same way.

### Task 2
`type`: auto
`files`: internal/media/segment.go, internal/media/manifest.go
`action`: Stream the init segment and media segments into a temp file, surface `os.CreateTemp` and file I/O errors, and keep the partial-failure cleanup behavior strict.
`verify`: Force a segment download failure and confirm the temp file is removed and the function returns an error.
`acceptance_criteria`: The code no longer buffers the entire payload in memory before decrypting.
