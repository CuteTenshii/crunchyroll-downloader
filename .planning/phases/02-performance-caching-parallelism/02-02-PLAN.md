<objective>
Parallelize audio version manifest fetching and license challenges across audio versions using golang.org/x/sync/errgroup, skipping the errgroup when only one audio version exists.

Per D-05 through D-08, D-12, D-13: errgroup fan-out with fail-fast, video stays sequential before audio fan-out, cache-first manifest access, deferred bulk stream cleanup.

**Purpose:** For episodes with 3-5 audio dubs, each version requires sequential manifest fetch (~200ms CDN) + license challenge (~300ms Crunchyroll license server). Parallelizing reduces this from N*500ms to ~500ms total.
**Output:** Modified episode.go with errgroup-based parallel audio loop, added golang.org/x/sync dependency, tests for parallel behavior.
</objective>

**Phase B — Parallel audio (versions [1..N]):**
Only if `len(versions) > 1`:

```go
g, gctx := errgroup.WithContext(ctx)
var mu sync.Mutex  // protects audioTracks and tempFiles in goroutines

for idx := 1; idx < len(versions); idx++ {
    idx := idx
    version := versions[idx]
    g.Go(func() error {
        // Cache-first manifest access
        manifest := media.GetCachedManifest(version.contentId)
        if manifest == nil {
            episode, err := client.GetEpisode(gctx, version.contentId)
            if err != nil {
                return fmt.Errorf("fetching episode for %s: %w", version.locale, err)
            }
            mu.Lock()
            activeStreams[version.contentId] = episode.Token
            mu.Unlock()

            manifestData, err := client.FetchManifest(gctx, episode.ManifestURL)
            if err != nil {
                return fmt.Errorf("fetching manifest for %s: %w", version.locale, err)
            }

            manifest, err = media.ParseManifest(manifestData)
            if err != nil {
                return fmt.Errorf("parsing manifest for %s: %w", version.locale, err)
            }
            media.SetCachedManifest(version.contentId, manifest)
        }

        pssh := drm.GetPssh(manifest)
        if pssh == nil {
            return fmt.Errorf("PSSH not found for %s", version.locale)
        }

        keys, err := drm.GetLicense(gctx, client, *pssh, version.contentId, ...)
        // ^ episode.Token from activeStreams — use activeStreams[version.contentId] after cache-hit path
        // For cache-hit path, episode.Token was stored in activeStreams at miss time.
        if err != nil {
            return fmt.Errorf("getting license for %s: %w", version.locale, err)
        }

        audioSet := manifest.Period[0].AdaptationSets[1]
        fmt.Printf("Downloading %s audio...\n", mux.TrackTitle(version.locale))
        audioBaseUrl, audioRepresentationId := media.GetAudioBaseUrl(audioSet, *audioQuality)
        if audioBaseUrl == nil {
            return fmt.Errorf("failed to get audio base URL for %s", version.locale)
        }

        audioFile, err := media.DownloadParts(gctx, client, audioBaseUrl, audioRepresentationId, audioSet, keys, workers)
        if err != nil {
            return fmt.Errorf("downloading audio for %s: %w", version.locale, err)
        }

        mu.Lock()
        tempFiles = append(tempFiles, audioFile)
        audioTracks = append(audioTracks, mux.MediaTrack{File: audioFile, Locale: version.locale})
        mu.Unlock()
        return nil
    })
}

if err := g.Wait(); err != nil {
    return fmt.Errorf("audio versions: %w", err)
}
```

Key implementation details:
- **Cache-hit path**: If the manifest is already cached (from i==0 or another goroutine), skip GetEpisode, FetchManifest, ParseManifest. But we still need the stream token for the DeleteStream cleanup. Handle this by: on cache-hit, the stream was already started in Phase A or by a previous goroutine. Actually, each contentId has its own stream token, and they're different for each version. So cache-hit only happens if the same contentId was processed already. In practice, each version has a different contentId, so cache-hit rarely happens during parallel execution (it caches at the contentId level).
- **activeStreams population**: Always populate activeStreams inside the goroutine when we call GetEpisode (cache-miss path), protected by mutex.
- **audioTracks**: Protected by mu.Lock() for the append.
- **tempFiles**: Protected by mu.Lock() for the append.
- **Use gctx everywhere inside g.Go** — the derived context from errgroup.WithContext, NOT the parent ctx. This ensures sibling errors cancel remaining work.
- **fmt.Printf calls** inside goroutines are safe — println is goroutine-safe in Go.
- **activeStreams map** is written from goroutines (mutex-protected) and read from the deferred cleanup on the main goroutine after g.Wait() returns. No concurrent read-write race.

**Phase C — Stream cleanup (deferred, already exists):**
The existing deferred cleanup at lines 97-109 already calls `client.DeleteStream` for all entries in `activeStreams`. No changes needed — it already handles cleanup regardless of sequential or parallel execution.

**Behavioral invariants to preserve:**
- The "all" lang expansion at lines 62-77 stays at the top.
- Subtitles download at lines 136-144 stays before the audio loop.
- The mux.MergeEverything call at line 218 stays after the loop/errgroup.
- The `completed = true` flag at line 221 stays.
- Error wrapping format: each goroutine error uses `fmt.Errorf("... %s: %w", version.locale, err)` matching existing patterns.

**Critical: remove the per-version DeleteStream calls and activeStreams deletions from the old loop body.** These exist at lines 210-215 in the current code. The deferred block handles all cleanup.

**Add sync and golang.org/x/sync/errgroup to imports:**


The existing `"fmt"` import stays. `"context"` stays. All other existing imports stay.
