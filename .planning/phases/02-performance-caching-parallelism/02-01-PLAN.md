<objective>
Create a thread-safe in-memory MPD manifest cache to eliminate redundant manifest fetching and parsing when downloading multiple audio versions of the same episode.

Per D-01 through D-04: cache is keyed by contentId, stores parsed *mpd.MPD, uses sync.RWMutex, no eviction.

**Purpose:** First fetch+parse of an MPD manifest takes ~200-500ms (CDN latency + XML parsing). With 3-5 audio versions, the savings from caching compound to ~1-2 seconds per episode.
**Output:** Exported GetCachedManifest/SetCachedManifest functions in media package, wired into episode.go's audio loop.
</objective>
