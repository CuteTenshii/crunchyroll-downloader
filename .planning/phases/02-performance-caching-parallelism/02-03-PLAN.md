  <files>internal/media/manifest.go</files>

  <action>
Replace the single GetBaseUrl function with two exported functions. Remove the old GetBaseUrl entirely.

**GetVideoBaseUrl(set *mpd.AdaptationSet, quality string) (*string, *string):**
- Takes the video-height-matching logic from the GetBaseUrl isVideoSet=true branch.
- If set is nil or has no representations, return nil, nil.
- For each representation: skip if BaseURL empty or ID nil or Height nil.
- Parse quality string (strip "p" suffix) as integer via strconv.ParseInt.
- If representation.Height matches the parsed quality integer, return (&BaseURL[0].Value, rep.ID).
- Fallback: return first available representation's BaseURL and ID if available, else nil, nil.

**GetAudioBaseUrl(set *mpd.AdaptationSet, quality string) (*string, *string):**
- Takes the audio-matching logic from the GetBaseUrl isVideoSet=false branch.
- If set is nil or has no representations, return nil, nil.
- For each representation: skip if BaseURL empty or ID nil.
- First check if rep.ID contains "audio/":
  - If rep.ID contains the quality string directly (existing path for "audio/" prefix IDs), return match.
- Otherwise check rep.Bandwidth with explicit switch/case per D-11:
  ```go
  switch quality {
  case "192k":
      if *rep.Bandwidth >= 192000 { return match }
  case "128k":
      if *rep.Bandwidth >= 128000 { return match }
  case "96k":
      if *rep.Bandwidth >= 96000 { return match }
  default:
      // Unknown quality — fall through
  }
  ```
- Fallback: return first available representation's BaseURL and ID if any representation exists, else nil, nil.

**Bandwidth matching logic migrated from GetBaseUrl (lines 40-48):**
The old code used string manipulation: `num := strings.ReplaceAll(quality, "k", "")` then numeric comparisons. Move this to the explicit switch/case above where each case uses the literal bandwidth threshold.

The `strings` import may still be needed by ExpandTimeline (it's not). Keep `strconv` and `strings` imports if still used, or remove if no longer needed.

Do NOT modify ParseManifest, ExpandTimeline, or any other function in manifest.go.
