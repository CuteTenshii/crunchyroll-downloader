# Phase 4 — UI Design Contract (CLI Terminal Output)

> Visual and interaction contract for terminal/CLI output. Generated by gsd-ui-researcher.
> Adapted for Go CLI — all sections reference terminal output conventions, not web design.

---

## Output Abstraction

| Property | Value |
|----------|-------|
| Output method | Custom `internal/output` package — **not** `slog` or raw `fmt.Printf` |
| Interface methods | `Info(msg)` — `Warn(msg)` — `Error(msg)` — `Debug(msg)` — `Progress(format, args...)` |
| Wiring | Package-level global set once in `main()` after flag parsing (same pattern as `internal/config`) |
| Source decision | D-01, D-02, D-03 |

All 43 `fmt.Printf` calls across 8 files replaced with the output interface.

### Mode Behavior

| Mode | Flag | Behavior |
|------|------|----------|
| Human (default) | neither `--quiet` nor `--json` | Colored ANSI terminal output, all messages and progress |
| JSON | `--json` | NDJSON structured events to stdout, errors also as JSON |
| Quiet | `--quiet` | Suppress progress output only (errors + warnings still print). AD: errors emit as JSON if `--json` also set. |
| Source decision | D-04, D-16 | |

## Terminal Output Layout

Terminal is 80-column monospace. All output uses fixed-width font (no web spacing tokens).

### Vertical Spacing Conventions

| Context | Spacing | Pattern |
|---------|---------|---------|
| Season header | 1 blank line after header | `"Downloading season N of Title (M episodes)\n\n"` |
| Episode start | New line | `"[Episode N/M] Title —\n"` (printed once at start) |
| Progress updates | Same line via `\r` | Carriage return overwrites current line — no extra newlines |
| Episode result | New line after progress | `"\n[Episode N/M] Title — ✓"` (result replaces progress area) |
| Between episodes | 1 blank line | `fmt.Println()` between episode outputs |
| Season summary | 1 blank line before, 1 after | `"\nSeason download complete.\n"` then error listing then `"\n"` |
| Batch mode header | 1 blank line before/after | `"=== [N/M] URL ===\n\n"` then blank line after result |
| Error listing | Indented by 2 spaces | `"  Episode N: error message\n"` |

Source: Existing patterns from `season.go:36`, `main.go:353-357`, and D-05 (multi-line per-episode).

### Line Width Guidelines

| Element | Max Width | Behavior on Overflow |
|---------|-----------|---------------------|
| Episode header | 80 chars | Truncate title with `...` |
| Progress line | 80 chars | Never overflows — fixed format |
| Error messages | 80 chars | Wrap to next line at word boundary, indented |
| Season summary | 80 chars | Wrap error messages, indent continuation |

## Output Format Patterns

(This section replaces "Typography" — terminal uses monospace font, no font configuration.)

### Message Format Templates

| Method | Prefix | Color | Format |
|--------|--------|-------|--------|
| `Info` | None (plain) | Default | `{message}` |
| `Warn` | `⚠` | Yellow (33) | `⚠ {message}` |
| `Error` | `✗` | Red (31) | `✗ {message}` |
| `Debug` | `[debug]` | Dim (90) | `[debug] {message}` |
| `Progress` | None | Default | `\r{formatted string}` (carriage return, no newline) |

### Numeric Formatting

| Data Type | Format | Example |
|-----------|--------|---------|
| Segment count | `{count}/{total}` | `145/212` |
| Percentage | `({N}%)` | `(68%)` |
| Speed | `{X.X} {unit}/s` | `12.4 MB/s`, `847.2 KB/s` |
| ETA | `{N}s` or `{N}m {N}s` | `ETA 23s`, `ETA 2m 14s` |
| File size | `{X.X} {unit}` | `847.2 MB`, `1.4 GB` |
| Duration | `{N}m {N}s` | `2m 34s` |

Source: D-12 (progress format), existing code patterns.

### Episode Output Layout (per D-05 multi-line)

```
[Episode 3/24] Attack on Titan S01E03 —          ← Printed once via Info
Downloaded 145/212 segments (68%) — 12.4 MB/s, ETA 23s  ← \r Progress line, updated 1/sec

[Episode 3/24] Attack on Titan S01E03 — ✓ 847.2 MB, 2m 34s  ← Result line on completion
```

**On error:**
```
[Episode 3/24] Attack on Titan S01E03 —
Downloaded 89/212 segments (42%) — 8.1 MB/s, ETA 27s

[Episode 3/24] Attack on Titan S01E03 — ✗ network error: connection reset by peer
```

## ANSI Color Scheme

(This section replaces "Color" — no surface/dominant/secondary concepts, only terminal ANSI.)

### Color Palette

| Role | ANSI Code | CSS Name | Usage |
|------|-----------|----------|-------|
| Reset / Default | `\033[0m` | — | Clear all formatting |
| Bold | `\033[1m` | bold | Season headers, episode numbers |
| Success | `\033[32m` | green | `✓` checkmark, completed count |
| Error | `\033[31m` | red | `✗` cross mark, error messages, failure count |
| Warning | `\033[33m` | yellow | `⚠` prefix, warning messages |
| Info Accent | `\033[36m` | cyan | Episode titles, series names, section headers |
| Dim | `\033[90m` | bright black | Debug messages, less important metadata |
| Progress numbers | `\033[32m` | green | Percentage, speed value, ETA value |
| Episode number | `\033[1m` | bold | `[Episode N/M]` bracket content |

### Color Application Rules

| Element | Color |
|---------|-------|
| `✓` (success symbol) | Green (32) |
| `✗` (failure symbol) | Red (31) |
| `⚠` (warning symbol) | Yellow (33) |
| `[Episode N/M]` | Bold (1) |
| Episode title | Cyan (36) |
| `Downloading season N of Title` | Bold (1) header, Cyan (36) title |
| Progress line label `"Downloaded"` | Default |
| Segment numbers `145/212` | Green (32) |
| Percentage `(68%)` | Green (32) |
| Speed value `12.4 MB/s` | Green (32) |
| ETA value `23s` | Green (32) |
| Error message text | Red (31) |
| Season summary `N of M episodes failed:` | Bold (1) if failures, else default |
| Debug `[debug]` prefix | Dim (90) |
| Batch `=== [N/M] ===` delimiters | Cyan (36) |
| File size on completion `847.2 MB` | Green (32) |
| Duration on completion `2m 34s` | Green (32) |

**Implementation:** Direct ANSI escape sequence constants in Go:

```go
const (
    ANSIReset  = "\033[0m"
    ANSIBold   = "\033[1m"
    ANSIDim    = "\033[90m"
    ANSIRed    = "\033[31m"
    ANSIGreen  = "\033[32m"
    ANSIYellow = "\033[33m"
    ANSICyan   = "\033[36m"
)
```

Wrap colored values with `ANSI{Color} + value + ANSIReset`.

Source: D-04 (ANSI color codes), D-06 (green ✓, red ✗).

## Message Format Copywriting Contract

(This section replaces standard "Copywriting" — adapted for terminal output messages.)

### Season-Level Messages

| Element | Template | Example |
|---------|----------|---------|
| Season start | `Downloading season {N} of {Title} ({M} episodes)` | `Downloading season 3 of Attack on Titan (24 episodes)` |
| Season success | *(no explicit message — implied by all episodes passing)* | — |
| Season failure summary | `Season {N} download complete. {F} of {M} episode(s) failed:\n{Error listing}` | `Season 3 download complete. 1 of 24 episode(s) failed:` |
| Season error listing | `"  Episode {N}: {error message}"` (one per failed episode) | `  Episode 7: network error: connection reset by peer` |
| Season complete (all pass) | `Season {N} download complete. All {M} episodes successful.` | `Season 3 download complete. All 24 episodes successful.` |
| Batch header | `=== [{N}/{M}] {URL} ===` | `=== [1/5] https://www.crunchyroll.com/watch/GRDQPQV3R ===` |
| Batch count | `Found {N} URLs to download` | `Found 5 URLs to download` |

Source: D-07 (inline + accumulated errors), D-08 (detailed season summary), UX-06.

### Episode-Level Messages

| Element | Template | Example |
|---------|----------|---------|
| Episode start | `[Episode {N}/{M}] {Title} (S{E:02}E{N:02}) —` | `[Episode 3/24] Attack on Titan (S03E03) —` |
| Episode skip | `[Episode {N}/{M}] {Title} — skipped (already downloaded)` | `[Episode 3/24] Attack on Titan — skipped (already downloaded)` |
| Success result | `[Episode {N}/{M}] {Title} — ✓ {size}, {duration}` | `[Episode 3/24] Attack on Titan — ✓ 847.2 MB, 2m 34s` |
| Error result | `[Episode {N}/{M}] {Title} — ✗ {error message}` | `[Episode 3/24] Attack on Titan — ✗ network error: connection reset by peer` |

Source: D-05, D-06, UX-02.

### Segment Progress (UX-03)

| Element | Format | Example |
|---------|--------|---------|
| Progress line | `Downloaded {N}/{M} segments ({P}%) — {S} MB/s, ETA {E}s` | `Downloaded 145/212 segments (68%) — 12.4 MB/s, ETA 23s` |
| Audio progress | `Downloaded {N}/{M} segments ({P}%) — {S} MB/s — {locale} audio` | `Downloaded 89/212 segments (42%) — 8.1 MB/s — en-US audio` |
| Subtitle progress | *(subtitles downloaded in one batch, no progress)* `Downloaded subtitles!` | `Downloaded subtitles!` |
| Video progress | `Downloaded {N}/{M} segments ({P}%) — {S} MB/s — video` | `Downloaded 145/212 segments (68%) — 12.4 MB/s — video` |

Source: D-09, D-10, D-11, D-12.

### Per-Episode Flow (During Download)

```
Downloading: {Title} (S{E:02}E{N:02}) from {Series}         ← Info (bold, cyan)
Audio locales: {langs} | Subtitle locales: {langs}          ← Info
Downloading subtitles for {locale}...                        ← Info
Downloaded subtitles!                                        ← Info (green checkmark)
Downloading {locale} audio...                                ← Info
Downloaded {N}/{M} segments ({P}%) — {S} MB/s, ETA {E}s     ← Progress (\r, 1/sec)
Downloading video...                                         ← Info
Downloaded {N}/{M} segments ({P}%) — {S} MB/s, ETA {E}s     ← Progress (\r, 1/sec)
[Episode {N}/{M}] {Title} — ✓ {size}, {duration}            ← Info (green ✓)
```

### Error Message Conventions

| Rule | Description |
|------|-------------|
| No stack traces | Never show Go stack traces to the user (UX-05) |
| Clean language | Describe what happened + what to do next |
| Prefix with `✗` | Red symbol for any error message (UX-06) |
| Inline visible | Error appears immediately at episode level (D-07) |
| Accumulated | Also collected in season summary (D-07, D-08) |
| No panic | All errors handled via returned `error` values (UX-01) |

Error message examples:

| Scenario | Output |
|----------|--------|
| Network failure | `✗ network error: connection to crunchyroll.com failed. Check your internet connection and try again.` |
| Auth failure | `✗ authentication failed: etp_rt cookie may be expired. Obtain a fresh cookie and retry.` |
| FFmpeg not found | `✗ FFmpeg not found: install FFmpeg and ensure it is on $PATH. See https://ffmpeg.org/download.html` |
| Disk full | `✗ disk full: no space left on device. Free up space or change output directory.` |
| Segment download failed | `✗ segment 42 download failed after 5 retries: connection reset by peer` |

## NDJSON Event Schema (for `--json` mode)

### Common Fields

Every NDJSON event includes:

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | Event type identifier |
| `timestamp` | string | ISO 8601 UTC timestamp (RFC3339) |

### Event: `episode_start`

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | `"episode_start"` |
| `timestamp` | string | ISO 8601 |
| `season_number` | int | Season number |
| `episode_number` | int | Episode number |
| `total_episodes` | int | Total episodes in season |
| `title` | string | Episode title |
| `series_title` | string | Series title |

### Event: `segment_progress`

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | `"segment_progress"` |
| `timestamp` | string | ISO 8601 |
| `episode_number` | int | Episode number |
| `downloaded` | int | Segments downloaded so far |
| `total` | int | Total segments to download |
| `percent` | float | Completion percentage (0.0–100.0) |
| `bytes_per_sec` | int64 | Rolling average speed in bytes/sec |
| `eta_secs` | int | Estimated remaining seconds |
| `stream` | string | Stream type: `"video"`, `"audio"`, or `"subtitle"` |
| `locale` | string | Language locale of the stream (e.g., `"en-US"`) |

### Event: `error`

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | `"error"` |
| `timestamp` | string | ISO 8601 |
| `message` | string | Human-readable error message (no stack traces) |
| `episode_number` | int | Episode number (0 if not episode-scoped) |
| `season_number` | int | Season number (0 if not season-scoped) |
| `fatal` | bool | Whether the error terminates the process |

### Event: `episode_complete`

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | `"episode_complete"` |
| `timestamp` | string | ISO 8601 |
| `season_number` | int | Season number |
| `episode_number` | int | Episode number |
| `title` | string | Episode title |
| `success` | bool | Whether the episode downloaded successfully |
| `error` | string | Error message (empty string on success) |
| `duration_secs` | float | Final episode duration in seconds |
| `size_bytes` | int64 | Final file size in bytes |

### Event: `season_summary`

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | `"season_summary"` |
| `timestamp` | string | ISO 8601 |
| `season_number` | int | Season number |
| `series_title` | string | Series title |
| `total_episodes` | int | Total episodes in season |
| `successful_episodes` | int | Episodes completed without error |
| `failed_episodes` | int | Episodes that failed |
| `errors` | array | Array of `{episode_number: int, title: string, message: string}` |

Source: D-13, D-14, D-15.
