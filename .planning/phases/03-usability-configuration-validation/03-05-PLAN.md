<objective>
Add CRUNCHYROLL_CLIENT_AUTH env var override for the hardcoded Basic Auth credential in auth.go.

**Purpose:** Crunchyroll can rotate the client credential at any time, breaking the downloader. The `CRUNCHYROLL_CLIENT_AUTH` env var allows users to override the default without recompiling. The hardcoded value is documented as the public default.

**Output:**
- `internal/api/auth.go` — Updated with getClientAuth() function and env var override
</objective>
