<action>
Add batch URL validation in main.go. This runs BEFORE the download loop and catches all invalid URLs upfront. It also refactors processURL to use url.Parse() (QOL-05) and fixes the && → || bug (QOL-04).

1. Add `import "net/url"` to imports.

2. Create `validateURL(rawURL string) error`:
   - Call `url.Parse(rawURL)` — if error, return fmt.Errorf("invalid URL: %w", err).
   - Extract path segments from `parsed.Path` — trim leading/trailing slashes, split on "/".
   - If fewer than 2 segments, return fmt.Errorf("URL path must contain content type and ID").
   - `contentType := parts[0]`, `contentID := parts[1]`.
   - If contentType != "watch" && contentType != "series", return fmt.Errorf("URL must be /watch/ or /series/...").
   - If `len(contentID) < 9 || len(contentID) > 14` (note: ||, not && — QOL-04 fix), return fmt.Errorf("content ID length must be 9-14 characters (got %d)", len(contentID)).
   - Return nil on success. Use the exact logic from RESEARCH.md code example at lines 391-434.

3. Create `validateAllURLs(urls []string) []invalidURL` with a local `invalidURL` struct `{URL string; Error string}`:
   - Iterate URLs, call validateURL on each.
   - Collect invalid results.
   - Return the slice.

4. In the batch URL handling section (current lines 150-163), restructure:
   a. After building the `urls` slice from the file, call `invalid := validateAllURLs(urls)`.
   b. If invalid is non-empty, print "Invalid URLs found:" then each invalid URL with its error, then `os.Exit(1)`.
   c. Then proceed with the download loop as before (printing count and processing each).
5. This runs per D-17: structure + content ID length validation only; no HTTP reachability check.

6. Remove the old string-split URL parsing from processURL — it now only uses url.Parse() via the validation that already ran (the inline validation in processURL can be removed since URLs are pre-validated; keep the contentType/contentID split using url.Parse internally for compatibility with pre-validation).

For main_test.go, add:
- `TestValidateURLValidWatchPath` — valid /watch/GGGGGGGGG (9 chars) returns nil.
- `TestValidateURLValidSeriesPath` — valid /series/GGGGGGGGGGGG (12 chars) returns nil.
- `TestValidateURLTooShort` — /watch/short (5 chars) returns error about length.
- `TestValidateURLTooLong` — /watch/GGGGGGGGGGGGGGG (15 chars) returns error about length.
- `TestValidateURLWrongContentType` — /browse/ id returns error about watch/series.
- `TestValidateURLTrailingSlash` — /watch/GGGGGGGGG/ with trailing slash passes (url.Parse handles it).
- `TestValidateURLWithQueryParams` — /watch/GGGGGGGGG?foo=bar passes (url.Parse strips query).
- `TestValidateAllURLsReportsAll` — mix of valid/invalid, verify all errors collected.
</action>
