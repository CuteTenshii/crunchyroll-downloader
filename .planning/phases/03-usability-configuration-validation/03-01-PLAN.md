## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config file → main.go | Untrusted user-written JSON loaded and parsed by the application |
| env var → main.go | Environment variables read by os.LookupEnv — assumed secure (process-local) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-01 | Information Disclosure | Config file (contains etp_rt) | medium | mitigate | Config file created with 0644 permissions; document in README to chmod 600 if secrets stored |
| T-03.1-02 | Tampering | Config file JSON | low | mitigate | Invalid JSON detected at Load time — main.go prints warning to stderr and falls through to defaults per D-04 |
| T-03.1-03 | Tampering | Config file path (XDG) | low | accept | Attacker would need filesystem write access to modify config; user's own config dir is trusted |
| T-03.1-04 | Information Disclosure | CRUNCHYROLL_ETP_RT in process env | medium | accept | Env var is per-process and not logged; flag value visible in `ps` but env var mitigates that (per RESEARCH.md state-of-the-art table) |
</threat_model>
